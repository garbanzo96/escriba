    Cómo usar Escriba

    1. Graba o abre una grabación. Si grabas, deja el computador cerca de quienes hablan. Al terminar, Escriba transcribe solo y el texto va apareciendo. Puede demorar tanto como dura la entrevista, según el computador.
    2. Escucha y corrige. Toca el minuto de un párrafo para oírlo desde ahí. El párrafo que suena se ilumina. Escribe directamente sobre el texto: se guarda solo.
    3. Marca quién habla. Toca la etiqueta de cada párrafo, o usa Alt + 1, Alt + 2… para asignar a la persona mientras escuchas.
    4. Guarda el resultado. El botón Exportar entrega un documento de Word o un texto simple.
